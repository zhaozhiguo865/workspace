# 走遍俄罗斯 第三册 学习大纲

## Урок 1 - 运动动词 (Глаголы движения)

### 核心语法
**定向运动 vs 不定向运动**
- идти (定向) / ходить (不定向) - 走
- ехать (定向) / ездить (不定向) - 乘车
- лететь (定向) / летать (不定向) - 飞
- плыть (定向) / плавать (不定向) - 游
- бежать (定向) / бегать (不定向) - 跑
- нести (定向) / носить (不定向) - 拿(步行)
- вести (定向) / водить (不定向) - 带领
- везти (定向) / возить (不定向) - 运送

### 用法区别
- **定向**: 一次具体、有方向的运动
- **不定向**: 多次、往返、习惯性、无固定方向

### 例句
- Я иду в школу. (我正在去学校)
- Я хожу в школу каждый день. (我每天上学)
- Он едет в Москву. (他正在去莫斯科)
- Он часто ездит в Москву. (他经常去莫斯科)

## Урок 2 - 动词体 (Виды глагола)

### 核心语法
**完成体 vs 未完成体**

| 未完成体 | 完成体 | 含义 |
|----------|--------|------|
| делать | сделать | 做 |
| писать | написать | 写 |
| читать | прочитать | 读 |
| говорить | сказать | 说 |
| смотреть | посмотреть | 看 |
| слушать | послушать | 听 |
| учить | выучить | 学习 |
| покупать | купить | 买 |
| готовить | приготовить | 准备 |
| есть | съесть | 吃 |
| пить | выпить | 喝 |

### 用法
- **未完成体**: 过程、习惯、重复、否定
- **完成体**: 结果、一次性、将来时

### 例句
- Я читаю книгу. (我在读书 - 过程)
- Я прочитал книгу. (我读完了书 - 结果)
- Я буду читать. (我将要读 - 将来未完成)
- Я прочитаю. (我将读完 - 将来完成)

## Урок 3 - 形动词 (Причастие)

### 核心语法
**主动形动词 vs 被动形动词**

**现在时主动形动词**: 动词现在时词干 + -ущ-/-ющ-/-ащ-/-ящ- + 形容词词尾
- чита**ющ**ий (正在读的)
- пиш**ущ**ий (正在写的)
- сид**ящ**ий (正在坐的)

**过去时主动形动词**: 动词过去时词干 + -вш- + 形容词词尾
- прочитавший (读过的)
- написавший (写过的)

**被动形动词**: 动词完成体 + -нн-/-т- + 形容词词尾
- прочитанный (被读过的)
- написанный (被写过的)

### 例句
- Студент, **читающий** книгу, мой друг. (正在读书的学生是我的朋友)
- Книга, **прочитанная** мной, интересная. (我读过的书很有趣)

## Урок 4 - 副动词 (Деепричастие)

### 核心语法
**未完成体副动词**: 动词现在时词干 + -а/-я
- читая (读着)
- пиша (写着) → пиш**я**
- сидя (坐着)

**完成体副动词**: 动词完成体 + -в/-вши/-чи
- прочитав (读完后)
- написав (写完后)
- придя (来了后)

### 用法
表示伴随动作或时间先后

### 例句
- **Читая** книгу, я делаю заметки. (读书时我做笔记)
- **Прочитав** книгу, я начал писать. (读完书后我开始写作)

## Урок 5 - 比较级和最高级 (Степени сравнения)

### 核心语法
**比较级**
- 形容词词干 + -ее/-ше: красивый → красив**ее**
- 特殊变化: хороший → лучше, плохой → хуже

**最高级**
- самый + 形容词: самый красивый
- 形容词词干 + -ейш-: красив**ейший**

### 例句
- Эта книга интересн**ее**. (这本书更有趣)
- Он **самый** умный. (他最聪明)

## Урок 6 - 数词和量词 (Числительные)

### 核心语法
**数量数词 + 名词的变格**
- 1 + 名词单数一格: один студент, одна книга
- 2-4 + 名词单数二格: два студента, три книги
- 5+ + 名词复数二格: пять студентов, десять книг

**集合数词**
- двое, трое, четверо, пятеро (用于人或某些名词)

### 例句
- У меня **две** книги. (我有两本书)
- В комнате **пять** студентов. (房间里有五个学生)

## Урок 7 - 时间表达 (Время)

### 核心语法
**钟点表达**
- 1:00 - час
- 2-4:00 - два/три/четыре часа
- 5+: пять/шесть/... часов

**分钟表达**
- 1:10 - десять минут второго
- 2:30 - половина третьего / два тридцать
- 3:45 - без пятнадцати четыре

### 词汇
| 俄语 | 中文 |
|------|------|
| час | 小时/点钟 |
| минута | 分钟 |
| половина | 半 |
| четверть | 一刻 |
| без | 差 |

## Урок 8 - 条件句 (Условные предложения)

### 核心语法
**真实条件句**: если + 现在时/将来时
- Если будет дождь, я останусь дома. (如果下雨，我就待在家里)

**虚拟条件句**: если бы + 过去时
- Если бы я знал, я бы пришёл. (如果我知道，我就来了)

---

## Урок 9 - 目的从句 (Придаточные цели)

### 核心语法
**чтобы + 过去时**
- Я пришёл, чтобы учиться. (我来是为了学习)
- Она говорит тихо, чтобы никто не слышал. (她小声说话，为了没人听见)

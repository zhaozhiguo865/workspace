# 长期记忆提取系统

_自动分析对话，提取并存储关键信息_

## 使用方法

在对话结束时，我会自动：
1. 分析本次对话内容
2. 提取值得记住的信息
3. 分类存储到对应文件

## 记忆分类

### preferences/ - 用户偏好
- 喜欢的工具/软件
- 工作习惯
- 沟通偏好

### habits/ - 习惯模式
- 常用指令
- 工作节奏
- 重复任务

### goals/ - 目标计划
- 短期目标
- 长期规划
- 项目意向

### people/ - 人际关系
- 重要联系人
- 关系背景
- 互动历史

### projects/ - 项目信息
- 进行中的项目
- 技术栈
- 关键决策

## 提取规则

**会记录**:
- 明确的偏好表达（"我喜欢...", "我讨厌..."）
- 重复出现的需求
- 重要的个人信息
- 目标和计划

**不会记录**:
- 一次性问题
- 敏感信息（密码、隐私）
- 临时情绪表达
- 已过时信息

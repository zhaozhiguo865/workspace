### 三、核心语法

#### 1. 数词 1-50 构成规则

**简单数词（1-10）**：
- 1-10: один, два, три, четыре, пять, шесть, семь, восемь, девять, десять

**复合数词（11-19）**：
- 以-надцать结尾：одиннадцать (11), двенадцать (12), тринадцать (13)...
- 重音在-надцать上

**整十数词（20-50）**：
- 20: двадцать
- 30: тридцать（重音在第一个音节）
- 40: сорок（特殊变化）
- 50: пятьдесят（重音在"де"）

**合成数词（21-29, 31-39, 41-49）**：
- 结构：整十数词 + 个位数
- 例：двадцать один (21), тридцать пять (35), сорок девять (49)

#### 2. 疑问代词 какой

**变格表**：
| 性/数 | 第一格 |
|-------|--------|
| 阳性 | како́й |
| 阴性 | кака́я |
| 中性 | како́е |
| 复数 | каки́е |

**用法**：
1. 询问性质、特征：
   - Како́й э́то дом? （这是什么样的房子？）
   - Это но́вый дом. （这是新房子。）

2. 询问哪一个（从多个中选择）：
   - Како́й слова́рь твой? （哪本词典是你的？）
   - Вот мой слова́рь. （这是我的词典。）

3. 与名词性数一致：
   - Како́й магази́н?（什么商店？）
   - Кака́я цена́?（什么价格？）
   - Како́е фо́то?（什么照片？）
   - Каки́е това́ры?（什么商品？）

#### 3. 购物常用句型

**询问价格**：
- Ско́лько сто́ит э́та кни́га? （这本书多少钱？）
- Кака́я цена́? （什么价格？）
- По чём э́то? （这个怎么卖？）

**表达购买意愿**：
- Мо́жно посмотре́ть? （可以看看吗？）
- Я беру́. （我买了。）
- Дайте, пожа́луйста. （请给我。）

**描述商品**：
- Э́то но́вый това́р. （这是新商品。）
- Э́то дорого́й пода́рок. （这是贵重的礼物。）
- Э́то дёшевая цена́. （这是便宜的价格。）

### 四、课后练习

#### 练习1：数字翻译
1. 25 → двадцать пять
2. 33 → тридцать три
3. 47 → сорок семь
4. 50 → пятьдесят
5. 21 → двадцать один

#### 练习2：用 какой 填空
1. _____ э́то кни́га? （Кака́я，阴性）
2. _____ э́то окно́? （Како́е，中性）
3. _____ э́то дома? （Каки́е，复数）
4. _____ э́то магази́н? （Како́й，阳性）

#### 练习3：翻译句子
1. 这本书多少钱？
   → Ско́лько сто́ит э́та кни́га?

2. 我买了。
   → Я беру́.

3. 这是什么商店？
   → Како́й э́то магази́н?

4. 这是新超市。
   → Это но́вый суперма́ркет.

## 十、前缀用法详解与例句

### 1. в-/вы- 用法对比

| 前缀 | 核心含义 | 用法说明 | 例句 | 翻译 |
|------|----------|----------|------|------|
| **в-** | 进入内部 | 表示从外到内的运动 | Он **вошёл** в комнату. | 他走进了房间。 |
| | | | Я **вбежал** в дом. | 我跑进了房子。 |
| | | | Птица **влетела** в окно. | 鸟飞进了窗户。 |
| **вы-** | 从内部出去 | 表示从内到外的运动 | Он **вышел** из комнаты. | 他走出了房间。 |
| | | | Мы **выехали** из города. | 我们驶出了城市。 |
| | | | Она **выбежала** из школы. | 她从学校跑了出来。 |

**用法要点**：
- в- + 第四格 = 进入某处
- вы- + 第二格 = 从某处出来
- 与运动动词搭配使用

### 2. при-/у- 用法对比

| 前缀 | 核心含义 | 用法说明 | 例句 | 翻译 |
|------|----------|----------|------|------|
| **при-** | 来到/接近 | 表示到达某地 | Гости **приехали** вчера. | 客人昨天到了。 |
| | | | Я **пришёл** на работу. | 我来到了工作地点。 |
| | | | Самолёт **прилетел** вовремя. | 飞机准时到达。 |
| **у-** | 离开/远去 | 表示从某地离开 | Он **ушёл** домой. | 他回家了。 |
| | | | Мы **уехали** из Москвы. | 我们离开了莫斯科。 |
| | | | Птицы **улетели** на юг. | 鸟儿飞去了南方。 |

**用法要点**：
- при- 强调到达的结果
- у- 强调离开的动作
- 常与表示地点的副词搭配

### 3. под-/от- 用法对比

| 前缀 | 核心含义 | 用法说明 | 例句 | 翻译 |
|------|----------|----------|------|------|
| **под-** | 接近/向上 | 表示向某物靠近 | Он **подошёл** к окну. | 他走近了窗户。 |
| | | | Машина **подъехала** к дому. | 汽车驶近了房子。 |
| | | | Я **поднял** руку. | 我举起了手。 |
| **от-** | 远离/离开 | 表示从某物离开 | Он **отошёл** от окна. | 他从窗户边走开了。 |
| | | | Машина **отъехала** от дома. | 汽车驶离了房子。 |
| | | | Я **опустил** руку. | 我放下了手。 |

**用法要点**：
- под- + 第三格 = 接近某物
- от- + 第二格 = 离开某物
- 可以表示空间或抽象概念的接近/远离

### 4. по- 多义用法

| 含义 | 用法说明 | 例句 | 翻译 |
|------|----------|------|------|
| **开始** | 表示动作的开始 | Он **заговорил** о погоде. | 他开始谈论天气。 |
| | | Дети **запели**. | 孩子们开始唱歌。 |
| **短暂** | 表示动作持续一会儿 | Я **почитаю** книгу. | 我读一会儿书。 |
| | | Мы **посидим** здесь. | 我们在这儿坐一会儿。 |
| **分散** | 表示向不同方向 | Люди **разошлись** по домам. | 人们各自回家了。 |
| | | Птицы **разлетелись**. | 鸟儿四散飞走了。 |
| **完成体** | 使动词成为完成体 | Я **построил** дом. | 我建成了房子。 |
| | | Она **покрасила** стену. | 她刷完了墙。 |

## 十三、词缀学习建议

1. **先掌握高频前缀**：в-/вы-, при-, у-, по-, на-, с-
2. **注意体对应**：未完成体→完成体的常见转换规律
3. **积累词根**：运动动词词根(-ход-, -езд-, -бег-等)
4. **识别词性**：通过后缀判断词性(-тель=人, -ство=抽象, -ный=形容词)
5. **组合记忆**：前缀+词根+后缀 = 完整词汇
6. **特殊前缀**：воз-/вз-, низ-/нис-, раз-/рас-, из-/ис-等需要单独记忆
7. **体转换**：掌握-ать/-ить, -ывать等后缀变化规律
8. **词族记忆**：以一个词根为核心，扩展记忆整个词族
9. **语境学习**：通过例句理解词缀的实际用法

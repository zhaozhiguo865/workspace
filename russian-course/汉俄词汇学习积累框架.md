## 三、词汇学习方法

### 3.1 每日学习计划

| 时间 | 内容 | 数量 |
|------|------|------|
| 早晨（30分钟） | 新词学习 | 20词 |
| 上午（15分钟） | 复习旧词 | 50词 |
| 下午（15分钟） | 例句阅读 | 10句 |
| 晚上（30分钟） | 写作练习 | 用新词造句 |
| **每日总计** | | **20新词 + 复习** |

**月度目标**：600新词
**达到5000词需要**：4个月

### 3.2 词汇记忆技巧

#### 1. 联想记忆法
- **形象联想**：море（海）→ 发音像"摸热"→ 海水摸起来热热的
- **词根联想**：писать（写）→ письмо（信）→ писатель（作家）
- **场景联想**：вокзал（火车站）→ 我在"我靠这站"等火车

#### 2. 词群记忆法
- **同根词**：учить, учитель, ученик, учёба, наука, учёный
- **同义词**：говорить, сказать, рассказывать, разговаривать
- **反义词**：большой-маленький, хороший-плохой, начать-кончить
- **同主题词**：вокзал, поезд, билет, пассажир, проводник

#### 3. 语境记忆法
- 在句子中记忆单词
- 在阅读中遇到生词立即查字典
- 用新词写短文或日记

#### 4. 间隔重复法
- 第1天：学习新词
- 第2天：复习
- 第4天：复习
- 第7天：复习
- 第15天：复习
- 第30天：复习

### 3.3 词汇应用练习

#### 造句练习
每个新词造3个句子：
1. 简单句（主谓宾）
2. 复合句（带从句）
3. 情景句（日常对话）

#### 翻译练习
- 汉译俄：将中文句子翻译成俄语
- 俄译汉：将俄语文章翻译成中文
- 回译：将自己翻译的俄文再译回中文对比

#### 写作练习
- 每日日记：用新学的词汇写日记
- 主题作文：每周写一篇主题作文
- 续写故事：给故事开头，用新词续写

## 五、词汇检测标准

### 5.1 掌握程度分级

| 级别 | 标准 | 检测方法 |
|------|------|---------|
| 认识 | 看到认识，知道大概意思 | 阅读测试 |
| 理解 | 能在语境中准确理解 | 选择题测试 |
| 运用 | 能在口语中使用 | 口语对话 |
| 掌握 | 能在写作中正确使用 | 写作测试 |
| 熟练 | 能自动反应，不假思索 | 快速反应测试 |

### 5.2 自测方法

**每日自测**
- 遮盖中文，看俄语说中文
- 遮盖俄语，看中文说俄语
- 听写测试
- 造句测试

**每周测试**
- 词汇量测试（在线测试）
- 阅读理解测试
- 写作测试（用本周新词）

**每月评估**
- 完整词汇量测试
- 综合能力评估
- 调整学习计划

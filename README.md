# OpenClaw 工作空间

这是我的 OpenClaw AI 助手工作空间，包含记忆、技能和配置。

## 目录结构

```
.
├── memory/          # 每日记忆记录
├── skills/          # 自定义技能
├── logs/            # 日志文件
├── AGENTS.md        # 代理配置
├── MEMORY.md        # 长期记忆
├── SOUL.md          # 助手人格
└── USER.md          # 用户信息
```

## 主要功能

- **记忆系统**：自动记录每日对话和事件
- **技能扩展**：支持自定义 Agent Skills
- **定时任务**：夜间维护、早间汇报
- **多语言支持**：俄语学习、中文交互

## 使用说明

1. 克隆仓库：`git clone https://github.com/zhaozhiguo865/workspace.git`
2. 安装 OpenClaw 并配置工作空间路径
3. 启动服务，开始与 AI 助手对话

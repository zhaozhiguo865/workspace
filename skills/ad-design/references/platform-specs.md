# 平台规格指南

## 抖音

### 视频规格
| 参数 | 规格 |
|------|------|
| 分辨率 | 1080×1920（9:16） |
| 帧率 | 30fps |
| 码率 | 推荐 |
| 时长 | 15s-3min（推荐60s内） |
| 格式 | MP4 |

### 封面规格
| 参数 | 规格 |
|------|------|
| 尺寸 | 1080×1920 |
| 文字 | 大字标题，居中或上1/3 |

### 设计要点
- 3秒黄金法则，开场抓人
- 大字报风格，字体≥60px
- 高对比配色，视觉冲击
- 竖屏满屏，信息集中

---

## 小红书

### 图片规格
| 类型 | 尺寸 | 比例 |
|------|------|------|
| 单图 | 1080×1440 | 3:4 |
| 单图（竖） | 1080×1920 | 9:16 |
| 单图（方） | 1080×1080 | 1:1 |
| 多图 | 统一比例 | - |

### 设计要点
- 拼图风格，信息密度高
- 滤镜质感，统一色调
- 真实感强，像生活分享
- 标签重要，底部留空

### 文字规范
- 标题：16-20字
- 正文：1000字以内
- 多用emoji分段
- 关键词前置

---

## 微信朋友圈广告

### 图片规格
| 类型 | 尺寸 |
|------|------|
| 单图 | 800×450（16:9） |
| 三图 | 800×800（1:1）×3 |
| 四图 | 800×800（1:1）×4 |
| 六图 | 800×800（1:1）×6 |

### 视频规格
| 参数 | 规格 |
|------|------|
| 分辨率 | 1280×720 |
| 时长 | 6-30s |
| 大小 | ≤100MB |

### 设计要点
- 品牌感强，信任度高
- 信息完整，转化路径清晰
- 适合深度内容
- CTA明确（了解详情/立即购买）

## 微博

### 图片规格
| 类型 | 尺寸 |
|------|------|
| 单图 | 建议1080×1920 |
| 多图 | 单张≤20MB，最多18张 |
| 长图 | 宽度1080，长度不限 |

### 设计要点
- 话题性强，蹭热点
- 适合传播，易转发
- 配图要吸睛
- 文案简短有力

---

## B站

### 视频封面
| 参数 | 规格 |
|------|------|
| 尺寸 | 1146×717（16:10） |
| 大小 | ≤5MB |
| 格式 | JPG/PNG |

### 设计要点
- 设计感强，年轻化
- 玩梗文化，懂用户
- 标题党但不过分
- 分区风格明显

## 文件输出规范

### 图片
| 用途 | 格式 | 质量 |
|------|------|------|
| 网页 | JPG/PNG | 72-150dpi |
| 印刷 | PDF/AI | 300dpi |
| 透明背景 | PNG | - |

|------|------|------|
| 通用 | MP4 | H.264 |
| 高质量 | MOV | ProRes |

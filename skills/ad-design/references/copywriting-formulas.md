# 广告文案公式库

## 标题公式

### 1. 数字+结果型
- "3个技巧，让你的广告点击率提升200%"
- "5分钟学会，写出10w+爆文"
- "7天见效，皮肤好到发光"

### 2. 痛点+解决方案型
- "熬夜党救星，一抹告别黑眼圈"
- "久坐腰痛？这个神器帮你缓解"
- "减肥总失败？可能是方法错了"

### 3. 悬念+好奇心型
- "这个方法，90%的文案都不知道"
- "为什么高手都在偷偷用它？"
- "花了10万学费，换来的经验"

### 4. 对比+反差型
- "月薪3千和3万，差距就在这"
- "普通人vs高手，设计思路大不同"
- "用前vs用后，效果惊人"

### 5. 身份+场景+结果型
- "大学生靠设计，月入过万"
- "宝妈在家做自媒体，比上班还赚"
- "程序员转行UI，薪资翻倍"

### 6. 直接价值承诺型
- "看完这个，你会感谢我"
- "学会这招，省下几千块"
- "今天教你，明天就能用"

### 7. 情感共鸣型
- "成年人的崩溃，从这一刻开始"
- "那些年，我们一起追过的梦想"
- "致每一个努力生活的你"

### 8. 反常识型
- "其实，你一直做错了"
- "真相是，越懒越瘦"
- "别再做这件事了，害人不浅"

## 正文结构

### AIDA模型
```
Attention（注意）→ Interest（兴趣）→ Desire（欲望）→ Action（行动）
```

**示例**：
- A：你是不是也经常加班到深夜？（痛点）
- I：这款护眼灯采用无频闪技术（特点）
- D：让你工作再久也不累眼（利益）
- A：现在下单立减50元（行动）

### SCQA模型
```
Situation（情境）→ Complication（冲突）→ Question（问题）→ Answer（答案）
```

**示例**：
- S：每天对着电脑8小时
- C：眼睛干涩、视力下降
- Q：如何保护眼睛健康？
- A：XX护眼灯，专业护眼光源

### PAS模型
```
Problem（问题）→ Agitate（激化）→ Solution（解决）
```

**示例**：
- P：皮肤暗沉无光
- A：用再多护肤品都没效果，出门没自信
- S：XX精华，28天焕亮肌肤

## 平台文案特点

### 抖音
- 短平快，3秒抓人
- 口语化，像朋友聊天
- 多用emoji和符号
- 结尾引导互动

### 小红书
- 真实感，像朋友推荐
- 详细体验分享
- 多用「亲测」「宝藏」等词
- 标签要精准

### 微信
- 深度内容，有理有据
- 故事性强，情感共鸣
- 适合长文案
- 引导关注/转发

### 微博
- 话题性强，蹭热点
- 简短有力，适合传播
- 多用@和#
- 配图要吸睛

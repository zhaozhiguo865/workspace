# 字幕样式模板库

## 模板A: 抖音爆款风
**适用**: 知识口播、产品种草

```
字体: 思源黑体 Bold / 阿里巴巴普惠体 Heavy
大小: 主标题 60-80px, 正文 40-50px
颜色: 白色填充 + 黑色描边 3-4px
动效: 逐字弹出(0.05s间隔) + 轻微缩放(1.0→1.1)
位置: 画面下方 1/4 处，居中
强调: 关键词放大120% + 黄色/红色高亮
```

## 模板B: 电影质感风
**适用**: 剧情、旅行、情感

```
字体: 思源宋体 / Noto Serif CJK
大小: 32-40px
颜色: 白色/米白，透明度90%
动效: 淡入(0.5s) + 向上漂移
位置: 底部居中，距底边 10%
特效: 轻微阴影，电影黑边(上下遮幅)
```

## 模板C: 活泼Vlog风
**适用**: 日常记录、探店、开箱

```
字体: 站酷快乐体 / 手写体
大小: 48-64px
颜色: 多彩配色，根据场景变化
动效: 弹跳入场 + 贴纸抖动
位置: 灵活，跟随画面主体
装饰: 小图标、emoji、手绘边框
```

## 模板D: 商务专业风
**适用**: 企业宣传、教程、报告

```
字体: 微软雅黑 / 苹方
大小: 36-48px
颜色: 深色背景用白字，浅色背景用深灰
动效: 左滑/右滑入场，简洁干净
位置: 统一左对齐或居中
排版: 要点化，一行一观点
```

## 模板E: 游戏燃向风
**适用**: 游戏集锦、电竞、高光

```
字体: 锐字真言体 / 优设标题黑
大小: 60-100px
颜色: 霓虹色、渐变、描边发光
动效: 冲击缩放 + 故障效果(Glitch)
位置: 画面中央或关键位置
特效: 粒子、光效、动态背景
```

## 字幕排版原则

### 可读性
- 每行不超过12个字
- 重要信息单独一行
- 避免遮挡画面主体

### 层次感
- 标题 > 副标题 > 正文
- 用大小/颜色/粗细区分
- 关键信息视觉突出

### 节奏感
- 字幕出现配合语音/音乐
- 停留时间: 阅读速度 × 1.5
- 消失动效不要太突兀

# 短视频文案公式库

## 标题公式

### 公式1: 数字+痛点+解决方案
- "3个技巧，让你的视频播放量翻10倍"
- "5分钟学会，告别剪辑小白"

### 公式2: 悬念+好奇心
- "这个方法，90%的人都不知道"
- "我花了3万学费，换来的经验"

### 公式3: 对比+反差
- "月薪3千和3万，差距就在这"
- "普通人vs高手，剪辑思路大不同"

### 公式4: 身份+场景+结果
- "大学生靠剪辑，月入过万"
- "宝妈在家剪视频，比上班还赚"

### 公式5: 直接价值承诺
- "看完这个，你会感谢我"
- "学会这招，省下几千块"

## 正文结构

### 知识分享型
```
钩子(3s) → 观点(5s) → 3个要点(30s) → 总结(5s) → CTA(5s)
```

### 产品种草型
```
痛点(3s) → 产品介绍(10s) → 使用演示(20s) → 效果对比(10s) → 购买引导(5s)
```

### 剧情叙事型
```
冲突(5s) → 发展(20s) → 高潮(15s) → 结局(5s) → 金句(3s)
```

## 封面文案

### 大字标题型
- 主标题: 4-8个字，最大字号
- 副标题: 补充说明，小一号

### 问题答案型
- 左侧: 问题/痛点
- 右侧: 答案/解决方案

### 对比冲突型
- 左右/上下对比
- 箭头指向结果

### 数字清单型
- 大数字 + 核心关键词
- 如: "5个技巧" "3步学会"

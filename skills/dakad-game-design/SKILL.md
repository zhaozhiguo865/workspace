## 工作流程

### 阶段 1：概念设计
1. 确定游戏类型（德式/美式/聚会/卡牌等）
2. 定义核心体验
3. 确定玩家数量与时长
4. 核心机制草图

### 阶段 2：原型设计
1. 最小可玩版本（MVP）
2. 基础规则编写
3. 初始组件清单
4. 首次 solo 测试

### 阶段 3：迭代优化
1. 内部测试反馈
2. 数值调整
3. 规则澄清
4. 组件优化

### 阶段 4：完善文档
1. 完整规则书
2. 视觉设计指南
3. 生产文件清单
4. 发布准备

## 设计原则

1. **简洁优于复杂** - 规则易懂，深度来自互动
2. **有意义的决策** - 每个选择都应有影响
3. **适当的随机性** - 随机创造变数，但不决定胜负
4. **清晰的反馈** - 玩家应理解自己的行为结果
5. **可扩展性** - 考虑未来扩展或变体的可能性

# 斗转星移 - 桌游设计文档

## 一、掼蛋核心机制分析

### 1.1 牌型组合系统
| 牌型 | 说明 | 大小比较 |
|------|------|----------|
| 单张 | 任意单牌 | 按点数比较 |
| 对子 | 两张同点数 | 按点数比较 |
| 三张 | 三张同点数 | 按点数比较 |
| 三带二 | 三张+对子 | 按三张部分比较 |
| 顺子 | 5张连续点数 | 按最大点数比较 |
| 连对 | 3对以上连续对子 | 按最大对子比较 |
| 钢板 | 2个连续三张 | 按最大三张比较 |
| 炸弹 | 4张同点数 | 按点数比较，可炸任何非炸弹牌型 |
| 同花顺 | 同花色顺子 | 大于普通炸弹 |
| 四大天王 | 4张王牌 | 最大牌型 |

### 1.2 升级系统
- 从2开始，每局根据双方排名升级
- 双下（一方包揽一二名）：升3级
- 单下（一方包揽一二名但非双下）：升2级
- 平局：升1级
- 先打过A的一方获胜

### 1.3 配合机制
- 2v2团队对战
- 对家合作，共享升级
- 需要记牌、传牌信号、战术配合

### 1.4 进贡/还贡规则
- 下游给上游进贡最大牌（红桃级牌除外）
- 上游选择一张牌还贡
- 双下时，双贡双还
- 抗贡：进贡方有两张大王可抗贡

## 二、差异化设计：斗转星移

### 2.1 核心创新点

#### 🌟 星位系统（核心机制）
- 四种星位：**日、月、星、辰**
- 每种星位对应一种特殊能力
- 玩家可在出牌时激活星位能力

#### 🌟 星轨机制（配合创新）
- 牌桌上形成"星轨"（公共牌堆）
- 玩家出牌可影响星轨，产生连锁效果
- 对家可通过星轨互相配合

#### 🌟 星力系统（资源管理）
- 每局获得星力点数
- 使用星位能力消耗星力
- 星力可储存，关键时刻爆发

### 2.2 与掼蛋的核心差异

| 维度 | 掼蛋 | 斗转星移 |
|------|------|----------|
| 核心体验 | 记牌+配合 | 策略+技能组合 |
| 资源系统 | 无 | 星力资源管理 |
| 配合方式 | 信号传递 | 星轨联动 |
| 随机性 | 发牌随机 | 可控的星位随机 |
| 深度来源 | 记牌深度 | 技能组合深度 |
| 新手友好 | 需要记牌基础 | 技能直观易懂 |

## 三、完整规则框架

### 3.1 游戏目标
- 4人游戏，2v2团队对战
- 率先将本队星位升至"紫微"（最高级）的队伍获胜
- 或在一局中获得足够星辉点数直接获胜

### 3.2 牌组构成

#### 基础牌（108张）
- 数字牌：1-10，每种数字4张，共40张
- 元素牌：风、火、水、土，每种10张，共40张
- 星位牌：日、月、星、辰，每种6张，共24张
- 特殊牌：黑洞4张

#### 牌面说明
| 牌类型 | 数量 | 功能 |
|--------|------|------|
| 数字牌 | 40张 | 基础出牌，组成顺子、连对 |
| 元素牌 | 40张 | 可配合数字牌激活元素反应 |
| 星位牌 | 24张 | 激活星位能力，储存星力 |
| 黑洞 | 4张 | 万能牌，可替代任何牌 |

### 3.3 星位系统详解

#### 四种星位
| 星位 | 图标 | 能力 | 消耗星力 |
|------|------|------|----------|
| **日** | ☀️ | 本回合出牌点数+2 | 1点 |
| **月** | 🌙 | 查看对家手牌3张 | 2点 |
| **星** | ⭐ | 复制上家牌型 | 2点 |
| **辰** | 🌌 | 跳过下家回合 | 3点 |

#### 星力获取
- 打出星位牌：获得1点对应星力
- 组成特定牌型：额外获得星力
- 对家配合成功：双方各获1点

### 3.4 星轨机制

#### 星轨规则
1. 游戏开始时，中央形成空星轨（可放5张牌）
2. 玩家出牌时，可选择将一张牌放入星轨
3. 星轨满5张时触发"星象"效果，然后清空

#### 星象效果（根据星轨组成）
| 星轨组成 | 效果名称 | 效果描述 |
|----------|----------|----------|
| 5张同元素 | 元素爆发 | 该元素牌本回合点数翻倍 |
| 5张连续数字 | 数字洪流 | 所有玩家抽1张牌 |
| 3+2组合 | 三星连珠 | 激活玩家获得2点星力 |
| 含黑洞 | 黑洞吞噬 | 随机移除一名玩家1张手牌 |
| 含4种星位 | 四象合一 | 本队星位直接升1级 |

### 3.5 出牌规则

#### 基本流程
1. **发牌**：每人13张手牌
2. **确定主星**：随机决定本局主星位（日/月/星/辰）
3. **出牌**：首家任意出牌，后续玩家需跟同牌型或更大牌型
4. **星位激活**：出牌时可声明消耗星力激活星位能力
5. **星轨放置**：出牌后可选择放一张牌入星轨
6. **轮流出牌**：无法或不想跟牌则过

#### 牌型大小
| 牌型 | 说明 | 大小规则 |
|------|------|----------|
| 单张 | 任意单牌 | 数字>元素>星位，同类型比点数 |
| 对子 | 两张同类型同点数 | 同上 |
| 顺子 | 3张以上连续数字 | 比最大数字 |
| 连对 | 2对以上连续对子 | 比最大对子 |
| 元素链 | 3张以上同元素 | 比张数，同张数比元素等级 |
| 星位组 | 3张以上星位牌 | 含主星位者大 |
| 黑洞 | 单张黑洞 | 可压任何单张 |

#### 元素等级
风(1) < 水(2) < 土(3) < 火(4)

### 3.6 胜负判定

#### 升级规则
- 每局结束，根据双方手牌剩余情况决定星位升级
- 先出完手牌的一方获得星辉：基础3点+剩余星力
- 星辉用于升级本队星位

#### 升级消耗
| 星位等级 | 名称 | 升至下一级所需星辉 |
|----------|------|-------------------|
| 1 | 初星 | 5 |
| 2 | 启明 | 8 |
| 3 | 荧惑 | 12 |
| 4 | 太白 | 15 |
| 5 | 紫微 | -（最高级）|

#### 胜利条件
1. **星位胜利**：一队星位达到紫微
2. **星辉胜利**：单局获得20+星辉直接获胜
3. **压制胜利**：连续3局获得比对方多50%以上星辉

### 3.7 进阶规则（可选）

#### 星座模式
- 每队选择一个星座（如：北斗、南斗）
- 星座提供独特的团队被动能力
- 增加策略深度和重开性

#### 星宿挑战
- 加入8张星宿牌（特殊事件）
- 随机触发星宿效果，增加变数

#### 双星模式
- 每人控制两个星位
- 可同时激活两种能力
- 适合高阶玩家

## 五、测试方案

### 5.1 测试目标
1. 验证星位系统平衡性
2. 测试星轨机制流畅度
3. 评估游戏时长控制
4. 检验团队配合体验

### 5.2 测试用例

#### 测试1：基础流程测试
- **目标**：验证基本规则可运行
- **步骤**：
  1. 4名测试者按规则进行完整一局
  2. 记录每轮出牌时间
  3. 记录规则疑问点
- **通过标准**：无重大规则冲突，平均单局<30分钟

#### 测试2：星位平衡测试
- **目标**：四种星位使用频率与胜率
- **数据收集**：
  | 测试局数 | 日胜率 | 月胜率 | 星胜率 | 辰胜率 |
  |----------|--------|--------|--------|--------|
  | 10局 | | | | |
- **通过标准**：各星位胜率在40%-60%之间

#### 测试3：星轨触发测试
- **目标**：星轨触发频率与体验
- **数据收集**：
  - 平均每局星轨触发次数
  - 各星象效果触发占比
  - 玩家对星轨的满意度评分
- **通过标准**：星轨触发3-5次/局，满意度>7分

#### 测试4：新手友好度测试
- **目标**：无桌游经验者的上手难度
- **步骤**：
  1. 邀请2名无经验测试者
  2. 仅提供规则书，无教学
  3. 记录首次游戏完成时间与错误率
- **通过标准**：首次游戏<45分钟，规则理解错误<3处

## 七、设计总结

### 核心体验
**"斗转星移"**是一款融合传统牌型组合与策略技能系统的团队卡牌游戏。玩家需要在出牌策略、星力管理、团队配合之间找到平衡，通过激活星位能力和利用星轨机制来获得优势。

### 创新亮点
1. **星位系统**：四种独特能力，增加策略维度
2. **星轨机制**：公共牌堆创造团队配合新方式
3. **星力资源**：可控的资源管理，关键时刻爆发
4. **渐进升级**：长期目标与单局目标的结合

### 目标玩家
- 喜欢掼蛋、斗地主等传统牌类游戏的玩家
- 希望尝试有技能系统的卡牌游戏玩家
- 喜欢团队配合与策略深度的玩家

### 后续扩展方向
1. **更多星位**：加入新的星位类型
2. **星座系统**：团队专属的被动能力
3. **单人模式**：AI对战与战役模式
4. **赛季内容**：限时星象事件与排名系统

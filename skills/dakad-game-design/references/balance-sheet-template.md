# 数值平衡表格模板

## 基础数值

| 组件名称 | 成本 | 收益 | 效率 | 使用频率 | 预期价值 |
|---------|------|------|------|----------|----------|
| 示例卡牌A | 2 | 3 | 1.5 | 高 | 3.5 |
| 示例卡牌B | 3 | 5 | 1.67 | 中 | 5.2 |

## 计算公式

### 效率计算
```
效率 = 收益 / 成本
```

### 预期价值
```
预期价值 = 基础收益 × 使用频率系数 × 情境系数
```

### 平衡检查
- 效率应在 1.2-2.0 之间
- 高成本组件效率可略低（1.2-1.5）
- 低成本组件效率可略高（1.5-2.0）

# 俄语学习 - 2026年6月15日 (周一)
## 主题：基础问候与自我介绍

### 新词汇 (10词)
| 俄语 | 中文 | 词性 |
|------|------|------|
| привет | 你好 | 感叹词 |
| здравствуйте | 您好 | 感叹词 |
| спасибо | 谢谢 | 感叹词 |
| пожалуйста | 请/不客气 | 感叹词 |
| да | 是 | 副词 |
| нет | 不 | 副词 |
| я | 我 | 代词 |
| ты | 你 | 代词 |
| он | 他 | 代词 |
| она | 她 | 代词 |

### 例句
- Привет! Как дела? (你好！最近怎么样？)
- Я студент. (我是学生。)
- Спасибо большое! (非常感谢！)

### 学习笔记
- 正式场合用 "здравствуйте"，朋友间用 "привет"
- "пожалуйста" 既是"请"也是"不客气"

## 主题：颜色与描述

|------|------|------|
| цвет | 颜色 | 名词 |
| красный | 红色 | 形容词 |
| синий | 蓝色 | 形容词 |
| белый | 白色 | 形容词 |
| чёрный | 黑色 | 形容词 |
| большой | 大的 | 形容词 |
| маленький | 小的 | 形容词 |
| хороший | 好的 | 形容词 |
| новый | 新的 | 形容词 |
| красивый | 美丽的 | 形容词 |

### 例句
- Какой твой любимый цвет? (你最喜欢什么颜色？)
| Это красивый дом. (这是一座漂亮的房子。)
- У меня новая машина. (我有一辆新车。)

### 学习笔记
- 俄语形容词有性、数、格的变化
- 以-ый结尾的形容词是阳性形式

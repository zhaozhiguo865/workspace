# 俄语学习 - 2026年6月17日 (周三)
## 主题：家庭成员

### 新词汇 (10词)
| 俄语 | 中文 | 词性 |
|------|------|------|
| семья | 家庭 | 名词 |
| мама | 妈妈 | 名词 |
| папа | 爸爸 | 名词 |
| брат | 兄弟 | 名词 |
| сестра | 姐妹 | 名词 |
| дом | 家/房子 | 名词 |
| друг | 朋友 | 名词 |
| человек | 人 | 名词 |
| ребёнок | 孩子 | 名词 |
| родители | 父母 | 名词 |

### 例句
- У меня большая семья. (我有一个大家庭。)
- Это мой брат. (这是我的兄弟。)
| Моя мама дома. (我妈妈在家。)

### 学习笔记
- "родители" 是复数形式，表示父母双方
- "друг" 是男性朋友，女性朋友是 "подруга"
